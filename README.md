## 📌 Overview

Welcome to my Python learning archive! This repository documents my journey from writing my very first `"Hello, World!"` script to building structured, Object-Oriented applications, data analysis scripts, and practical automation tools.

It serves as a central hub for all my exercises, practice modules, and core projects created while mastering Python fundamentals and advanced concepts.

## 🚀 Key Features & Highlights

- **Structured Modules:** Cleanly organized folders ranging from basics to advanced paradigms.
- **Object-Oriented Design (OOP):** Implementation of classes, inheritance, encapsulation, and custom modules.
- **Data & Automation:** Practice scripts focusing on file handling, data structures, and algorithmic logic.
- **Clean Code & Git Workflow:** Standardized code formatting and consistent version control throughout the journey.
